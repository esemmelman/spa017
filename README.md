# spa017 — Spanish reflexive verbs

Practice online: https://esemmelman.github.io/spa017/

Ten questions and eighteen blanks with corrected answers, shuffled choices, immediate feedback, scoring, and restart. Press a question to toggle its English translation. Pictures omitted. Uses ustedes for Linda y tú.

The earlier possessive-adjective quiz is available at https://esemmelman.github.io/spa017/possessives.html.

Open index.html to practice offline. No dependencies or build step. GitHub Pages serves the root of the main branch.

# Preterite (Regular)

Practice online: https://esemmelman.github.io/spa017/

Fourteen questions with seventeen blanks, an infinitive verb bank, shuffled conjugated choices, immediate feedback, scoring, and restart. Press a question to toggle its English translation. Large question and answer fonts. Question 11 correctly uses vivieron.

Open index.html to practice offline. No dependencies or build step. GitHub Pages serves the root of the main branch.

# spa017 — Gustar and similar verbs

Practice online: https://esemmelman.github.io/spa017/

Ten questions with twenty blanks, shuffled choices, immediate feedback, scoring, and restart. Press a question to toggle its English translation. Large question and answer fonts. Uses ustedes for Juan y tú.

Open index.html to practice offline. No dependencies or build step. GitHub Pages serves the root of the main branch.
